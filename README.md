# a0-5-approval-spike

Disposable public test fixture for the Archit OS A0.5 approval-mechanics spike,
inside a disposable organization created solely for this experiment.

It contains **no** production code, **no** secrets, **no** credentials and
**no** connection to any cloud account. Every identifier and digest in
`deploy/intent.json` is fake.

Both this repository and its organization are scheduled for deletion after
independent review. Do not depend on either.
